IFK Bankeryd – programbladssida

Filer:
- index.html        själva webbsidan
- logo.png          IFK Bankeryd-logga
- programblad.pdf   programbladet som besökare kan läsa/ladda ner

Så uppdaterar du programbladet:
1. Ta din nya PDF.
2. Döp den till programblad.pdf.
3. Ersätt den gamla filen i samma mapp.
4. Publicera/ladda upp den uppdaterade mappen.

QR-koden:
QR-koden skapas automatiskt från den adress där index.html publiceras.
Det betyder att samma QR-kod fortsätter fungera när du byter programblad,
så länge sidans webbadress är oförändrad.
